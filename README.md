# PokeLoop

포켓몬 + 무협 + 방치형/증분형 RPG 프로토타입.

## 현재 구현

- PC 웹 3열 레이아웃
- 주인공 1마리 고정 패널
- 레벨 대신 나이 기반 시간 흐름
- BS / IV / 무제한 EV 표시
- IV에 따른 EV 수련 속도
- 기술 성급 수련
- 지역 선택형 탐험
- 환생 시 EV / IV 초기화
- 기술 전생 숙련 계승
- 생애 로그

프로토타입 테스트 속도를 위해 현실 1초를 게임 내 1개월로 사용합니다.

## 실행

npm install

npm run dev

## 빌드

npm run build

## 현재 핵심 루프

수련 → 강해짐 → 기술 수련 → 탐험 → 환생 → 다음 생에서 더 빠른 성장

초기 단계에서는 콘텐츠 양보다 이 루프의 재미 검증을 우선합니다.
