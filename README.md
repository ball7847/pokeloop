# PokeLoop

PC 브라우저 기준으로 만든 방치형 웹게임 초기 뼈대입니다.

## 현재 구현

- 3열 PC 전용 대시보드 UI
- 탐험 / 포켓몬 / 도구 / 마을 / 도감 탭
- 포켓몬 3마리 동시 출전
- 3초 단위 자동 행동
- 1x / 1.5x / 2x / 3x 전투 속도
- 속공 사용 시 PP 획득
- PP가 강공 요구량 이상이면 강공 우선 사용
- 전투 중 현재 HP 유지
- 전멸 또는 수동 귀환 시 전원 회복
- 50% 빈 조우 + 지역별 몬스터 조우표
- 코인 / 식량 / 나무 / 돌 보상
- 탐험 기록 및 최근 획득 표시
- localStorage 저장 / 초기화

## 구조

- `index.html` — 화면 구조
- `styles.css` — PC UI
- `app.js` — 상태, 자동 탐험, 전투, PP, 저장 로직

## 설계 방향

길드마스터의 PC 정보 밀도와 방치 탐험 흐름을 참고하되 PokeLoop에서는 포켓몬 자체의 성능이 중심이 되도록 구성합니다.

전투 빌드의 핵심 요소:

1. 기본 스탯과 타입
2. 속공 / 강공
3. 특성 2개
4. 도구 1개

도구 1개는 단순 소폭 스탯 보너스가 아니라 특성 1개와 비슷한 파워 버짓을 가진 커스터마이징 슬롯을 목표로 합니다.
