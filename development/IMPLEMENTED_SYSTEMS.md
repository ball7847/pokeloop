## 2. 메타몽 기본 능력치 및 표시

- 초기 메타몽: **HP 10 / 공격 1 / 공격 주기 3000ms**. 일반 기본값: 방어·특수공격·특수방어·마비·독·해독·회복 0, 명중 100%, 회피 0, 최소 피해 85%, 최대 피해 100% (`src/core/dittoStats.js`).
- 능력치는 HP·공격·방어·특수공격·특수방어·스피드·최소/최대 피해량 외에 연타·마비·독·해독·회복·명중·회피도 데이터 필드로 관리한다. 기본값/표시 여부는 `src/core/dittoStats.js`의 공통 메타데이터를 따른다.
- 기본값인 능력치는 대부분 숨기되 핵심 초기 능력치는 표시. 표시 수치의 소수 자릿수와 단위는 `formatStatValue`/큰 수 포맷터가 담당한다.
- 능력치 표시 문자열은 `dittoStats.js`의 공통 메타데이터/라벨 함수가 담당한다. SVG 상태/타입 아이콘은 `public/assets/` 활용.

## 3. 자동 전투·피해·상태이상

- `src/core/combatEngine.js`의 `startBattle → advanceBattle → resolveAttack → finish` 흐름. 명시 선택한 포켓몬과 실시간 공격 주기 기반 자동 전투. 동시에 공격 가능하면 **플레이어 먼저** 처리.
- 명중 확률: `accuracy<=0`이면 0; 그 외 `max(0,min(1,(min(accuracy,100)-scaledDodge)/100))`, `scaledDodge=dodge/(accuracy/100)`(accuracy>100), 아니면 dodge.
- 물리 피해 채널: `max(0, 공격 × 피해 배율 - 방어)`; 특수: `max(0, 특수공격 × 피해 배율 - 특수방어)`. 각 채널의 피해 배율은 최소~최대 피해 퍼센트 범위에서 **정수 퍼센트 난수**로 개별 판정. 두 채널 합계를 HP에 적용한다. 타입 상성/STAB/동화도는 이 함수에 직접 연결되어 있지 않다.
- 전투 중 공격속도 최소 간격 100ms. `advanceBattle`의 한 번 처리 간격은 최대 5000ms; 시간에 따른 공격 순서를 반복 시뮬레이션한다.
- **연타**: 능력치 × 0.1%로 즉시 추가 타격; 1000당 1회 확정, 잔여 수치만큼 추가 1회 확률. 추가 타격의 명중/피해 난수는 독립 처리하며 독·해독 처리는 공격 주기와 독립적으로 매초 진행.
- **마비**: 공격 시 누적 마비가 있으면 25% 확률로 누적치 전부를 소모하고 다음 공격 주기를 누적치(ms)만큼 연장한다. 현재 공격 자체는 취소되지 않는다.
- **독**: 명중 시 상대에게 누적하며, 공격 행동 종료가 아닌 매 1초마다 누적 독 수치만큼 HP 피해를 준다. **해독**: 같은 초에 독 피해에 앞서 누적 독을 해독 수치만큼 차감한다(최저 0). 빗나감·마비·공격속도에 영향받지 않는다.
- **회복**: 공용 1초 상태 틱에서 각 대상에게 **해독 → 독 피해 → 생존한 경우 회복** 순서로 적용한다. 독으로 HP 0 이하가 되면 같은 초에 회복하지 못하고 패배 처리한다. 최대 HP를 넘지 않는다. 새 전투에서는 초 타이머를 초기화하며 끝없는 허기의 남은 HP·상태이상은 유지한다. 메타몽과 적 모두에 적용한다.
- 메타몽/적에 동일한 물리·특수·독 전투 계산 경로 적용. 전투 HP와 기본 능력치 HP는 구별됨.
- 전투 시각 이벤트(`src/core/combatVisualEvents.js`, `src/components/CombatPanel.jsx`): **물리 빨강 / 특수 파랑 / 독 보라 / 회복 초록색 +실제 회복량 / 고정 흰색 CSS만 준비**; 명중 실패 MISS, 무피해 0. 물리/특수는 숫자 별도 생성. 과잉 피해는 실제 잃은 HP까지만 표시. 팝업 유지 시간 약 1.2초.
- 공격바는 `CombatBarAnimator.jsx`의 `requestAnimationFrame`으로 부드럽게 표현하되 실제 전투 상태는 바꾸지 않는다.

## 4. 지역·포켓몬·진행

- 정적 포켓몬 데이터: `src/core/wildCatalog.js`; 출현·진화·공개 API: `src/core/wildData.js`. 지역 수용량 하드 상한은 없으며, `appearedInRegion`에서 구성된 포켓몬 전체를 야생 카드로 표시한다. 24마리 기본 비율과 별개로 진화체·상위 희귀도 개체를 추가할 수 있다.
- **시작의 평원**(`starting-plains`): 꼬렛 → 구구 → 망키 → 깨비참 → 주뱃 → [6번 안흔한 스타터 슬롯: 이상해씨/파이리/꼬부기 중 등장한 1종] → 나옹 → 꼬마돌 → 아라리 → 꼬리선 → 켄타로스. 스타터 슬롯은 미등장 시 빈칸 없이 생략하며, 나옹부터 고정 순서 7~11번이다. 코드는 스타터 `W010602-01`~`W010602-03`, 나옹 `W010701`~켄타로스 `W011101`로 지정했다. 안흔한 스타터 데이터는 있으나 `UNCOMMON_BASE_CHANCE=0`이므로 초기 자연 발생하지 않는다.
- 시작 기본 세 포켓몬만 도전 가능. 서로 **다른 종의 첫 승리** 때마다 해당 지역의 다음 기본 포켓몬이 1마리씩 해금된다. 반복 처치로 추가 해금되지 않는다.
- **등장 코드 전체 적용:** 모든 등록 포켓몬은 `encounterCode`를 갖는다. 형식은 `R지역번호(1자리) + 지역 슬롯(2자리) + 희귀도(2자리)`, 동일 슬롯의 복수 후보는 `-01` 등의 후보 번호, 진화형은 부모 슬롯을 공유하며 `-E1` 등의 진화 단계 suffix를 사용한다. 슬롯은 조건부 미등장 시에도 고정되고 종 ID 및 저장 키와 별개다. 2지역 코드는 캐터피 `W020101`, 단데기 `W020101-E1`, 뿔충이 `W020201`, 딱충이 `W020201-E1`, 테일로 `W020301`, 푸푸린 `W020401`, 피카츄 `W020502`, 니드런♂ `W020601`, 니드런♀ `W020701`, 덩쿠리 `W020801`, 비버니 `W020901`, 비구술 `W021001`, 트로피우스 `W021101`이다. 피카츄는 기존처럼 조건부로만 등장한다.
- **베리숲**(`berry-forest`): 캐터피 → [단데기(진화 후 삽입)] → 뿔충이 → [딱충이(진화 후 삽입)] → 테일로 → 푸푸린 → [피카츄(조건부 안흔함)] → 니드런♂ → 니드런♀ → 덩쿠리 → 비버니 → 비구술 → 트로피우스. 기본 상태에는 피카츄가 보이지 않으며, 진화체는 각 부모 첫 승리 이후 나타난다. 피카츄는 특별 등장 플래그가 있어야 노출.
- **베리숲 밸런스 패치:** 캐터피 HP90/공격12, 단데기 HP150/공격20/방어11, 뿔충이 HP80/공격14, 딱충이 HP160/공격20/방어10, 테일로 HP80/공격11·보상 공격+2.76/속도-20/타입별 에너지27.6, 푸푸린 HP180/공격6/특공20/특방4/스피드2000ms·보상 HP+18/특공+5/타입별 에너지39, 피카츄 HP250/공격25/특공25/속도1025ms/마비250·보상 공격+25/마비+25/전기 에너지25, 니드런♂ HP230/공격57/속도2730ms/명중80%/최소 피해량50%/최대 피해량150%·공격 보상+5.7(최대 피해량 보상+3.2 유지), 니드런♀ HP220/공격21/독10/속도2750ms. 덩쿠리 HP195/특공15.5/회복5/스피드1600ms·보상 HP+11.4/회복+1.14 및 풀 타입 에너지 11.4. 비버니 HP390/공격25/특공15/스피드2900ms·보상 HP+20/공격+4/노말 에너지40. 비구술 HP40/공격30/방어32/특공50/특방52/스피드990ms·보상 스피드-28ms/벌레·물 각각 에너지28. 트로피우스 HP990/공격68/특공72/회복46/스피드5100ms·보상 HP+50/공격+10/특공+10/회복+10/풀·비행 각각 에너지100. 미지정 보상은 기존 유지.
- 베리숲 해금: 시작의 평원 **기본 라인업의 70% 이상**을 서로 다른 종 첫 승리로 처치(현재 기본 10종 기준 7종).
- 각 지역 포켓몬당 **최대 10회 처치**. 처치 보상: `기본 보상 / (1+기존 처치 횟수)`. 타입 에너지도 동일 감소 규칙. `scaledReward` 참조.
- 시작 평원 예시: 꼬렛 공격+1; 구구 HP+1; 망키 HP+5.6/공격+2(공격 주기 1800ms); 깨비참 HP+2.1/공격+1; 주뱃 공격+1/스피드-20.
